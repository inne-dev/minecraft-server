# Bootstrap plugins

- HazelwoodAuth.jar is built from the application source in hazelwood-card/minecraft-auth-plugin. Its seasonal-icon polling code depends on the portal endpoint described in the root README.
- TPA-3.0.jar and TradeCycle-2.1.0.jar are kept here as the current server-compatible artifacts.
- The other third-party plugins are downloaded for the configured Paper version at container startup.
